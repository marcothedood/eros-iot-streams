# eros-iot-streams

IoT data importer for the NEMO Horizon project (EROS4NRG pilot).
Reads energy meter streams and loads them into MinIO for the downstream pipeline.
Python, containerised, deployed on Kubernetes by [eros4nrg](https://github.com/marcothedood/eros4nrg).
See the umbrella repo for architecture, manifests and the full platform.
